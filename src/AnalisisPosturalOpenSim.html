    Descarga los puntos 3D del cuerpo como marcadores de OpenSim, con las mismas posturas elegidas para el .mot. No incluye imágenes.

    Posturas para 3DSSPP (University of Michigan), con las mismas posturas elegidas para el .mot, como posiciones de las articulaciones en cm. El .sloc se abre con Animation → Import LOC File: cada postura es un fotograma. El archivo de lote se ejecuta con Task Input → Run Batch File: analiza cada postura con la persona y la carga indicadas y guarda los resultados en un archivo terminado en «_export.txt». La cabeza, C7/T1, el esternón, L5/S1 y el centro de agarre de las manos se estiman a partir de los puntos detectados.

    Los videos exportados, las imágenes y los proyectos contienen datos personales de las personas grabadas: guárdelos en un lugar protegido y compártalos solo con quien deba verlos.
